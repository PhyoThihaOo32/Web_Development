Description List

A description list in HTML is used to display a list of terms and their descriptions. It is created using the <dl> tag, where each term is defined with the <dt> tag and each description is written using the <dd> tag. This type of list is commonly used for definitions, glossaries, or name–value pairs.

Examples

What is HTML?
HTML is a markup language used to create and structure web pages.
What is a description list?
A description list is used to display terms and their meanings or explanations.
Which tag is best for FAQs in HTML?
The description list is best for FAQs because it pairs questions with answers.
Is HTML a programming language?
No, HTML is a markup language, not a programming language.
Why is HTML important?
HTML is important because it forms the basic structure of every website.

Ordered List Definition

An ordered list in HTML is created using the ol tag and is used when the sequence of items is important. Each item is enclosed in an li tag, and numbering can be customized using attributes such as type, start, and reversed.

Examples

Cities

  1. New York
  2. Buffalo
  3. Oregon

Fruits

  1. Apple
  2. Orange
  3. Strawberry

Music

  1. Rock
  2. R&B
  3. Jazz

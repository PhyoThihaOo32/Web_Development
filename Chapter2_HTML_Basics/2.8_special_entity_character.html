Definition

An entity character in HTML is a special code used to display reserved or special characters
that cannot be written directly in HTML. Entity characters start with an ampersand (&) and end with a semicolon (;).
For example, < is used to display the less-than sign , > displays the greater-than sign >, and &
displays the ampersand &. Entity characters are commonly used to show HTML tags as text, symbols like
copyright ©, and characters that might otherwise be interpreted as HTML code.

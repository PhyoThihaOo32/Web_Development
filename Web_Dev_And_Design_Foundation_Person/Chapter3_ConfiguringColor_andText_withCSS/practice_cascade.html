CSS Cascade — Simple Explanation

How the Cascade Works (Priority Order)

  • Inline styles (highest priority) Styles written directly inside an HTML tag override others.
  • Internal CSS
  • External CSS (linked stylesheet)
  • Browser default styles (lowest priority)

Specificity Rule

If two rules conflict, the one with higher specificity wins.
Priority from highest to lowest.

  • • ID selector → #header
  • • Class selector → .menu
  • • Element selector → p

Short Exam Definition

The CSS cascade is the set of rules that determines which style is applied to an element when multiple styles conflict, based on priority, specificity, and source order.
